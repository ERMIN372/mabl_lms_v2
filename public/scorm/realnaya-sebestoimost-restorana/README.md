# Реальная себестоимость и операционные издержки ресторана

Папка ждёт файлы **этого** пакета. Ранее сюда по ошибке был загружен пакет
«Когнитивистика и развитие мышления» — из-за этого курс открывался чужим
содержимым; ошибочные файлы удалены.

Что загрузить: **содержимое** распакованного архива именно ресторанного курса —
папку `res/`, файл `imsmanifest.xml` и остальные файлы из корня архива.

Как проверить, что архив правильный, перед загрузкой: открыть в нём
`res/index.html` и убедиться, что в теге `<title>` написано
«Реальная себестоимость и операционные издержки ресторана». В правильном архиве
около 77 файлов, среди них несколько картинок по 7–15 МБ.

Точка входа: `res/index.html`
(итоговый адрес — `/scorm/realnaya-sebestoimost-restorana/res/index.html`).

Пакет уже зарегистрирован в `src/data/scormPackages.ts` — после загрузки файлов
он сразу заработает. Скрипты с расширением `.j_` чинятся автоматически при сборке.

Этот файл можно удалить после загрузки пакета.
