# Реальная себестоимость и операционные издержки ресторана

Сюда нужно загрузить **содержимое** распакованного SCORM-архива: папку `res/`,
файл `imsmanifest.xml` и остальные файлы из корня архива.

Точка входа после загрузки: `res/index.html`
(итоговый адрес — `/scorm/realnaya-sebestoimost-restorana/res/index.html`).

Пакет уже зарегистрирован в `src/data/scormPackages.ts`, поэтому после загрузки
файлов он сразу появится в админке: «SCORM-пакеты» → «Пакеты в репозитории».

Этот файл можно удалить после загрузки пакета.
